# Brand Assets Directory (`public/assets/`)

Place your custom brand logos and graphic assets here to have them automatically rendered across the storefront and admin consoles:

## Primary Files:
- `public/assets/logo.png` - Primary Navbar Logo & Emblem (Rendered beside `NEELSAREEHOUSE` in the top navigation bar).
- `public/assets/logo-transparent.png` - Transparent background PNG version for dark modes & hero banners.
- `public/assets/logo.webp` - Highly-optimized WebP asset for ultra-fast CDN delivery.
- `public/assets/brand-symbol.png` - Circular emblem mark for favicons & mobile badges.

Any file placed in `public/assets/filename.png` is instantly accessible in the app via `/assets/filename.png`.
